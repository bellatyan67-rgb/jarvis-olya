# ДЖАРВИС — ОЛЯ

Персональный голосовой помощник с неоновым интерфейсом.

## Возможности

- Голосовой ввод и озвучивание ответов.
- Задачи и заметки.
- Учёт доходов и расходов.
- Напоминания.
- Поиск в интернете.
- Калькулятор и конвертация температуры.

## Публикация

Проект предназначен для GitHub Pages.

Это стартовая версия помощника. Для подключения полноценного искусственного интеллекта потребуется серверная часть.
